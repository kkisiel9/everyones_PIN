# PIN Checker Program

This program checks if the entered PIN matches a predefined PIN, and grants access if it's correct.

## Features

- **PIN Check**: Verifies whether the entered PIN matches the correct one.
- **Access Granting**: If the PIN is correct, access is granted.
- **Maximum Attempts**: Limits the number of attempts to enter the correct PIN.
- **Attempt Tracking**: Tracks and displays the remaining attempts to enter the correct PIN.
